>#Problem Statement:

Many beginners learning programming need simple yet engaging projects to practice concepts such as loops, conditionals, input validation, and randomness. This project addresses the need for an interactive Python game that challenges users to guess a randomly generated secret number within a limited number of attempts with feedback after each guess.
Scope of the Project
This project focuses on creating a command-line Python game suitable for learning basic programming constructs. It covers random number generation, user input handling, conditional statements for feedback, and looping mechanisms for game progression and attempt limits. The scope is limited to numbers within a predefined range and is designed for single-player interaction.

>#Target Users:

Beginner Python programmers and coding learners.
Educators looking for simple projects to teach programming fundamentals.
Anyone interested in a fun, interactive guessing game in a terminal environment.

>#High-Level Features:

Random generation of a secret number within a user-defined range.
Four guesses allowed to find the secret number.
Feedback after each guess indicating if the guess was too high, too low, or correct.
Input validation to ensure guesses fall within the valid range.
Clear messages to guide the player and indicate game outcomes.
Simple and user-friendly command-line interface.
